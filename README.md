A trip planning and destination discovery app where users create trips, build day-by-day itineraries, and manage activities with location search and map view.

Frontend: Next.js (App Router), React, TypeScript
Styling: Tailwind CSS
State Management: Redux Toolkit
Routing: Next.js file-based routing (dynamic [id] trip routes)
Authentication: Firebase Authentication
Maps & Location: Leaflet (location search, trip map view)
Database: Firestore
